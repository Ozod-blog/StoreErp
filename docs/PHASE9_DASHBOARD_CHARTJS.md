# Dashboard Chart.js update

- Bosh sahifadagi savdo dinamikasi Chart.js (`react-chartjs-2`) Line chart bilan almashtirildi.
- Tooltip orqali kunlik savdo va qaytarish summalari ko‘rinadi.
- Grafik ostida oxirgi 7 kunning savdo, qaytarish va sof savdo jadvali qo‘shildi.
- `frontend/package.json` ichiga `chart.js` va `react-chartjs-2` qo‘shildi.

## O‘rnatish

`frontend` papkasida `npm install` bajaring, so‘ng `npm run dev` bilan ishga tushiring.

Grafik ma’lumotlari mavjud `/reports/sales` API javobidan olinadi; demo/soxta raqamlar qo‘shilmagan.
